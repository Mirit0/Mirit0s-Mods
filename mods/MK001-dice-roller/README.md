# MK001 Dice Roller

Roll animated 3D tabletop dice or flip a coin with Capri. Supports D4, D6, D8, D10, D12, D20 and D100 (two percentile dice), with numbered faces, cyberpunk visuals and Natural Commentary (reads her personality, notes, memories, and recent messages).
Now with SOUNDS

- Kind: code
- Made by: Mirit0
- Version: 1.7.15

## How to use

Say or type a command such as:

- `d20`, `roll a twenty`, or `can you do a d8?`
- `give d100`, `roll one hundred`, or `roll a one hundred sided die`
- `3d6`, `three d six`, `four dee twelve`, or `4 d100`
- `roll a d20 for initiative`
- `roll a d12 for damage`
- `roll a d6 for luck`
- `flip coin`, `toss a coin`, or `heads or tails?`
- `roll again` or `flip again` to repeat the most recent completed roll (within three minutes)


You can roll up to four dice at once, including percentile dice. The dice tumble in a temporary window and land on their selected numbered faces before Capri announces the result. Coin flips settle on heads or tails.

While Capri is running a job, Dice Roller does not interrupt her job. A roll in progress cancels when a job starts. The message passes through to Capri's normal handling.

personal or urgent messages are not captured by Dice Roller. Unsupported or ambiguous requests go to Capri as normal. 

This mod reads Capri's **personality, notes, memories, and recent chat messages**, and includes excerpts in the AI request to create an in character response to the dice result. If Capri uses an online provider the context is sent to that configured AI provider. If the configured provider runs locally it is processed locally. This behavior is part of the mod's AI commentary feature, not a separate memory system.
